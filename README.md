# 🍲 بيت ماما (Beit Mama) - نظام إدارة وطلب الأكل البيتي بلغة Java

تم تطوير وتجهيز نظام متكامل بلغة **Java** مع واجهة سطح مكتب **Java Swing** للإدارة، وخادم **Java Web Server** مدمج يوفر واجهات تفاعلية للعملاء والأمهات متوافقة مع شاشات الهواتف والكمبيوتر.

## ⚙️ متطلبات التشغيل (Prerequisites)

1. **Java Development Kit 25 (LTS) أو أحدث** لتطبيق سطح المكتب:
   - تأكد من تثبيت Java على جهازك عبر تحميل [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) أو [Adoptium Temurin](https://adoptium.net/).
   - بعد التثبيت يمكنك التأكد بكتابة: `java -version` في الطرفية (Terminal).
   - يتطلب تجميع تطبيق سطح المكتب Java 25 أو أحدث.
   - مشروع Android منفصل عن تطبيق سطح المكتب، ويحتفظ بمستوى مصدر Java 17 لضمان توافق Android؛ استخدم JDK 17 لتشغيل Gradle/Android Gradle Plugin الحالي.

2. **قاعدة البيانات**:
   - النظام مهيأ افتراضياً ليعمل عبر **SQLite**؛ يتم إنشاء قاعدة البيانات المحلية وتهيئتها عند تشغيل التطبيق، ولا تُرفع بياناتها إلى Git.
   - لاستخدام MySQL: قم باستيراد ملف [schema.sql](file:///Users/mac/.gemini/antigravity/scratch/beit-mama/db/schema.sql) وتعيين `USE_MYSQL = true` داخل كلاس [`DatabaseManager`](file:///Users/mac/.gemini/antigravity/scratch/beit-mama/src/com/beitmama/dao/DatabaseManager.java).

## 🚀 طريقة التجميع والتشغيل (How to Run)

### 1. تجميع الأكواد (Compile):
من داخل مجلد المشروع:
```bash
mvn compile
```

### 2. التشغيل (Run):
```bash
export BEITMAMA_ADMIN_PASSWORD='استخدم-كلمة-مرور-قوية-وفريدة-لا-تقل-عن-12-حرفاً'
mvn exec:java -Dexec.mainClass=com.beitmama.Main
```

- ستفتح لك مباشرة نافذة **Java Swing** لتسجيل دخول المدير:
  - **البريد الإلكتروني**: `admin@beitmama.com`
  - **كلمة المرور الأولية**: القيمة التي عيّنتها في `BEITMAMA_ADMIN_PASSWORD` قبل أول تشغيل؛ لا توجد كلمة مرور افتراضية.
- وفي نفس الوقت، يعمل خادم الويب للعملاء والأمهات على:
  👉 **`http://localhost:8080/`**
- إذا كان المنفذ 8080 مستخدماً، يمكن تشغيل المشروع على منفذ بديل:
  ```bash
  mvn exec:java -Dexec.mainClass=com.beitmama.Main -Dbeitmama.port=8081
  ```

## ✨ الميزات

- **متجر العملاء:** البحث عن الوجبات والأمهات، التصفية حسب التصنيف، والترتيب حسب السعر أو تقييم الأم.
- **سلة الطلبات:** تجمع عدة وجبات من أم واحدة، مع حساب الإجمالي والتحقق من المخزون على الخادم.
- **بيانات العميل والطلب:** حفظ الهاتف والعنوان ووسيلة التواصل، وتسجيل الدفع النقدي عند الاستلام أو التوصيل مع كل طلب.
- **إدارة الأم:** إضافة وتعديل وحذف الوجبات، تحديد الكمية وتاريخ انتهاء التوفر، ومتابعة الطلبات وتحديث حالتها.
- **بيانات الأم في المتجر:** رقم الهاتف مطلوب للتواصل عند التسجيل، ويظهر اسم المنطقة فقط على كروت الوجبات دون عنوان الاستلام أو الهاتف.
- **إدارة المدير:** إنشاء دعوات الأمهات وإلغاؤها، اعتماد الحسابات، ومتابعة الطلبات والإحصائيات.
- **إدارة المستخدمين:** البحث عن العملاء أو جميع المستخدمين برقم الهاتف، ومراجعة بيانات الأمهات وأرقام هواتفهن واعتماد الحسابات.
- **التوصيل والاستلام:** اختيار الاستلام من الأم أو إرسال عنوان للتوصيل؛ رسوم التوصيل يتم الاتفاق عليها مباشرة.
- **التقييمات:** يمكن للعميل تقييم الطلب المكتمل مرة واحدة، وتظهر مراجعات الأم ومتوسط تقييمها في المتجر.
- **التنبيهات:** تحديث الطلبات تلقائياً داخل لوحة الأم وصفحة طلباتي عند تغيّر الحالة.
- **إعدادات الحساب:** تغيير كلمة المرور بعد التحقق من الحالية، وجلسات دخول عبر Cookie محمية بـ `HttpOnly` و`SameSite`.

استعادة كلمة المرور عبر البريد أو الرسائل القصيرة تتطلب إعداد مزود خارجي؛ المتاح حالياً هو تغيير كلمة المرور بعد تسجيل الدخول. جلسات الدخول محفوظة في الذاكرة وتنتهي عند إيقاف الخادم.

## 🔒 الميزات الأمنية والوظيفية المنفذة

1. **نظام دعوات الأمهات الفريد (Invitation System):**
   - الرموز تُنشأ مشفرة ولا يتم تخزين الرمز الصريح في القاعدة بل بصمته `token_hash` بنظام SHA-256.
   - التحقق يتم في الخادم (Server-side) لمنع استخدام الرمز مرتين بحماية المعاملات (Concurrency & Transaction safe).
2. **عناوين الأمهات المحمية:**
   - عنوان استلام الأكل لا يظهر للعامة؛ بل يظهر للعميل حصراً بعد اعتماد الطلب. المعروض على كروت المتجر هو اسم المنطقة فقط.
3. **تثبيت الأسعار ومنع التلاعب:**
   - يتم سحب وحساب أسعار الوجبات والمجموع والكميات من الخادم مباشرة داخل كلاس [`OrderDao`](file:///Users/mac/.gemini/antigravity/scratch/beit-mama/src/com/beitmama/dao/OrderDao.java) لمنع تلاعب المتصفح.
4. **تشفير كلمات المرور:**
   - تشفير كلمات المرور باستخدام Salt عشوائي لكل مستخدم وتجزئة آمنة SHA-256.
